# Nonogram

Jeu de **Nonogram développé en Python avec PyGame** dans le cadre d'un **projet académique de BUT Informatique**.

Le Nonogram est un puzzle logique dans lequel le joueur doit remplir une grille à partir d'indices indiquant le nombre de cases consécutives à remplir sur chaque ligne et chaque colonne.

Le projet a permis de mettre en pratique la **programmation Python**, la **programmation orientée objet**, la gestion d'une **interface graphique avec PyGame** ainsi que la logique nécessaire à la gestion et à la résolution d'une grille.

## Fonctionnalités

* Affichage d'une grille de Nonogram
* Interaction avec la grille à l'aide de PyGame
* Sélection et modification des cases
* Affichage des indices des lignes et des colonnes
* Vérification des choix du joueur
* Gestion de l'état de la partie
* Détection de la résolution de la grille

## Installation

### Prérequis

* Python 3
* pip

Installer PyGame :

```bash
pip install pygame
```

Il est également possible d'utiliser un environnement virtuel :

```bash
python -m venv venv
```

Sous Linux/macOS :

```bash
source venv/bin/activate
```

Sous Windows :

```bash
venv\Scripts\activate
```

Puis installer PyGame :

```bash
pip install pygame
```

## Lancement

Après l'installation de PyGame, lancer le programme principal avec Python :

```bash
python <fichier_principal>.py
```

Le nom du fichier principal peut varier selon l'organisation du projet.
